# Original enzUI wallpapers

Six original 2560×1440 illustrations: Aurora, Dusk Dunes, Alpine Dawn, Tidal,
Ember and Orbit. They are generated by `tools/make-wallpapers.py` with Pillow;
no third-party photographs or downloaded artwork are included.

These original assets use the [MIT license](LICENSE), matching the workspace's
declared license. To regenerate, give the
generator an empty output directory. To add the packaged images to your gallery:

```sh
scripts/install-wallpapers "$HOME/Pictures/Wallpapers"
```

Installation is explicit and never overwrites existing names. Settings reads
Pictures/Wallpapers without modifying originals; selecting a picture imports a
bounded, normalized copy into the profile's private wallpaper cache.
